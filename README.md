Python File Organizer
Project Description

This project is a Python script that automatically organizes files into folders based on their file extensions.

Technologies Used
Python
os module
shutil module
Features
Identifies file extensions.
Creates separate folders for different file types.
Moves files into their respective folders.
Handles files without extensions.
Avoids overwriting existing files.
How to Run
Install Python.
Open the project folder in Visual Studio Code.
Open the terminal.
Run python file_organizer.py.
Enter the folder path you want to organize.
Learning Outcomes

Learned file handling, folder management, and automation using Python.
